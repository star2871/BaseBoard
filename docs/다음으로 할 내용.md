#### **8단계: 실시간 경기 UI 컴포넌트 개발**

- **목표**: `야구앱 기획문서.pdf`에 명시된 실시간 경기 상황판의 핵심 UI 요소들을 개발합니다. 이 컴포넌트들은 7단계에서 만든 API와 소켓 이벤트를 통해 전달받은 데이터를 시각적으로 표현하는 역할을 합니다.
- **주요 개발 내용**:
  - **스코어보드 (`Scoreboard.jsx`)**: 팀 이름, 현재 스코어, 이닝 정보를 표시하는 컴포넌트.
  - **볼카운트 (`BSOCount.jsx`)**: 현재 타자의 볼, 스트라이크, 아웃 카운트를 시각적으로 보여주는 컴포넌트.
  - **주자 상태 (`RunnersOnBase.jsx`)**: 1루, 2루, 3루의 주자 유무를 다이아몬드 형태로 표시하는 컴포넌트.
  - **실시간 이벤트 피드 (`EventFeed.jsx`)**: '안타', '삼진' 등 경기의 주요 이벤트 로그를 시간순으로 보여주는 컴포넌트.

#### **9단계: 실시간 경기 페이지 통합 및 대시보드 연동**

- **목표**: 8단계에서 개발한 개별 UI 컴포넌트들을 조합하여 완전한 실시간 경기 상세 페이지를 만들고, 대시보드에서도 현재 진행 중인 경기를 쉽게 확인할 수 있도록 연동합니다.
- **주요 개발 내용**:
  - **실시간 경기 페이지 생성 (`LiveGamePage.jsx`)**: 진행 중인 경기의 모든 정보를 한눈에 볼 수 있도록 8단계에서 만든 컴포넌트들을 통합하여 페이지를 구성합니다.
  - **데이터 연동**: `socketStore`를 통해 수신되는 `game:live:updated` 이벤트를 `LiveGamePage`에 연결하여 모든 정보가 실시간으로 자동 업데이트되도록 구현합니다.
  - **대시보드 위젯 추가**: 대시보드(`DashboardPage.jsx`)에 현재 진행 중인 경기가 있을 경우, 해당 경기의 핵심 정보(스코어, 이닝 등)를 보여주는 미니 위젯을 추가하고, 클릭 시 `LiveGamePage`로 이동하도록 구현합니다.
