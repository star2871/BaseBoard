## **1. 프로젝트 시작 및 기본 구조 설정 (1단계)**

- **목표**: `baseball_dashboard_architecture.pdf` 문서를 기반으로 프론트엔드와 백엔드를 함께 관리할 수 있는 모노레포(Monorepo) 구조를 설정하고, 각 앱의 초기 환경을 구성합니다.
- **실행 내역**:
  - `apps/client` (React, Vite)와 `apps/server` (Node.js, Express)로 구성된 프로젝트 기본 폴더 구조 생성.
  - `Tailwind CSS`를 프론트엔드에 적용하고 `Design_System_Material3.pdf` 기반의 초기 색상 테마 설정.
  - 각 앱에 필요한 기본 의존성 (`react`, `express`, `socket.io` 등) 설치.

## **2. 데이터베이스 및 API 기본 구현 (2단계)**

- **목표**: `야구앱 기획문서.pdf`를 참고하여 핵심 데이터 모델의 DB 스키마를 설계하고, 데이터를 조회할 수 있는 기본 API를 구현합니다.
- **실행 내역**:
  - `mongoose`를 사용하여 MongoDB 연결 설정.
  - `Team`, `Player`, `Game` 모델의 스키마 정의.
  - 선수, 팀, 경기 목록을 조회(`GET`)할 수 있는 REST API 엔드포인트 구현.

## **3. 프론트엔드 레이아웃 및 기능 구현 (3단계)**

- **목표**: `야구 분석 대시보드 UI 디자인 와이드프레임.png`을 바탕으로 앱의 전체적인 레이아웃과 기본 컴포넌트 구조를 설정합니다.
- **실행 내역**:
  - `react-router-dom`을 이용한 페이지 라우팅 설정.
  - 사이드바 네비게이션과 메인 콘텐츠 영역으로 구성된 `MainLayout` 구현.
  - **(사용자 요청)** 사이드바 프로필 클릭 시 동작 변경:
    1. 초기: 로그아웃 (`alert`) 기능 추가.
    2. 변경: 프로필 수정 모달 (`ProfileModal`)을 띄우는 기능으로 수정.

## **4. 피로도 분석 엔진 구현 (4단계)**

- **목표**: `fatigue-engine` 설계를 바탕으로 선수의 활동 데이터에 따라 피로도를 계산하는 핵심 로직을 구현합니다.
- **실행 내역**:
  - `packages/fatigue-engine` 모듈 생성 및 피로도 계산 함수 (`calculateFatigue`) 구현.
  - 계산된 피로도를 DB에 업데이트하는 `POST /api/players/:id/fatigue` API 엔드포인트 추가.

## **5. 실시간 통신 및 상세 페이지 기능 강화 (5단계)**

- **목표**: '실시간 경기 대시보드'와 '피로도 변화 알림'을 위해 `Socket.io`를 설정하고, 상세 페이지의 기능을 고도화합니다.
- **실행 내역**:
  - 피로도 업데이트 시 `player:fatigue:updated` 이벤트를 발생시켜 클라이언트에 실시간 알림 전송.
  - `Zustand`를 사용한 `socketStore`를 생성하여 프론트엔드에서 실시간 데이터 수신 및 처리.
  - **(사용자 요청)** 실시간 알림 클릭 시 해당 선수의 상세 페이지로 이동하는 기능 추가.
  - **(사용자 요청)** 선수 상세 페이지에 기능 추가:
    1. 해당 선수의 최근 경기 기록 목록 표시.
    2. `recharts`를 사용한 피로도 변화 추이 차트 시각화.
    3. 피로도 차트의 특정 지점 클릭 시, 해당 날짜의 경기 상세 정보 모달 표시.
  - **(사용자 요청)** 경기 상세 정보 모달에 기능 추가:
    1. 양 팀의 선발 라인업 정보 표시.
    2. 라인업의 선수 이름 클릭 시 해당 선수의 상세 페이지로 이동.

## **6. 대시보드 위젯 및 선수 상태 보드 구현 (6단계)**

- **목표**: 대시보드의 핵심 정보들을 한눈에 파악할 수 있도록 다양한 위젯과 선수 상태 보드를 구현합니다.
- **실행 내역**:
  - **(사용자 요청)** 대시보드에 위젯 추가:
    1. 다음 경기 일정과 시작까지 남은 시간을 보여주는 카운트다운 위젯.
    2. 팀의 승/패/승률을 계산하여 보여주는 팀 순위 위젯.
  - **(사용자 요청)** 팀 순위 위젯에서 특정 팀 클릭 시 해당 팀의 상세 페이지로 이동 기능 추가.
  - **(사용자 요청)** 팀 상세 페이지에 해당 팀의 최근 경기 기록 목록 표시 기능 추가.
  - `Zustand`를 사용한 `playerStore`를 생성하여 선수 데이터를 통합 관리.
  - 실시간으로 피로도 변경이 반영되는 **선수 상태 보드** 구현.
  - **(사용자 요청)** 선수 상태 보드에 기능 추가:
    1. 포지션 및 피로도 수준별 필터링 기능.
    2. 선수 이름 검색 기능.

## **7. 프로젝트 구조 정리 및 다음 단계 준비**

- **목표**: `baseball_dashboard_architecture.pdf` 문서에 명시된 폴더 구조에 맞게 프로젝트 전체 파일을 재구성하여 유지보수성을 향상시킵니다.
- **실행 내역**:
  - **(사용자 요청)** 백엔드(`apps/server`)와 프론트엔드(`apps/client`)의 파일들을 `models`, `routes`, `components`, `pages`, `store` 등 기능별 폴더로 재배치하고 코드 내 경로 수정 완료.
- **현재 단계**: **실시간 경기 센터 구현 (7단계)**
  - `Game` 모델에 실시간 경기 정보(`liveState`) 필드 추가.
  - 실시간 경기 상태를 업데이트하고 전파하는 `PUT /api/games/:id/live` API 구현 완료.
